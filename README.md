# Dex Analysis Bot

Dex Analysis Bot is a professional Telegram bot for cryptocurrency token analysis.

## Features

- AI Token Analysis
- Solana Token Scanner
- Rug Risk Detection
- Liquidity Analysis
- Whale Tracking
- Holder Analysis
- Momentum Detection
- AI Scoring
- Auto Signal Detection
- Telegram Auto Alerts

## APIs

- DexScreener
- BirdEye
- Helius
- RugCheck
