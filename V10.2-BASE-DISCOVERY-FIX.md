# V10.2 Base Discovery Fix

## What changed
- Added an optional GeckoTerminal **new-pools discovery source for Base**.
- GeckoTerminal is used only to discover fresh Base token addresses.
- Each discovered address is enriched through the existing DexScreener token-pairs endpoint.
- The existing scanner remains authoritative for:
  - 1s–48h age
  - $10,000–$1,000,000 market cap
  - liquidity/volume/transaction filters
  - 45% minimum buy ratio
  - security checks
  - final signal gates
- No Solana discovery logic was changed.
- No market-cap limit was increased or lowered.
- No security protection was removed.

## Verification

- A mocked GeckoTerminal response was also parsed successfully.
