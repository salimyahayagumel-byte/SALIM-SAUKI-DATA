# SALIM SAUKI DATA V8.6

## Main fixes

1. FluxRPC
   - Preferred Solana RPC when `FLUXRPC_RPC_URL` or `FLUXRPC_API_KEY` is configured.
   - Existing Solana RPC fallbacks remain.

2. API diagnostics
   - Added `check_apis.py`.
   - API keys are not printed.

3. Auto Signal diagnostics
   - Every scan reports why candidates were rejected.
   - Helps identify whether final signal, recommendation, security, or score gates are blocking delivery.

4. Group cleanup
   - Temporary deletion failures are retried.
   - Startup verifies bot membership and `can_delete_messages`.
   - Same-token cleanup/main-bot polling conflict is handled safely.
   - Separate HTTP transports are used for separate bot tokens.

## Important

`.env` and live SQLite databases are intentionally not included in the release ZIP.
Keep your existing `.env` and `salim_sauki_data.db`.
