# V8.8 — RELAXED SIGNALS + TELEGRAM HTTPX FIX

## Changes

- Market-cap range is unchanged: **$10,000–$5,000,000**.
- Relaxed final signal filters to increase candidate/signal discovery:
  - Security threshold: 70
  - AI threshold: 60
  - GEM signal threshold: 65
  - Strong GEM threshold: 72
  - Minimum liquidity: $10,000
  - Minimum buy ratio: 50%
  - Minimum volume/MC ratio: 0.03
  - Minimum transactions: 20
- Relaxed Auto Signal gates:
  - Security: 70
  - Recommendation: 65
  - Final score: 65
- Relaxed recommendation thresholds while keeping core Base honeypot checks and Solana authority checks.
- Lowered the security score threshold used for `should_pass` from 90 to 70, but **did not disable the underlying security checks**.
- Telegram `HTTPXRequest` now uses:
  - `trust_env=False`
  - HTTP/1.1
  - extended timeouts
- Applied the same Telegram transport settings to the optional cleanup bot.

## Important

This version is intentionally more permissive and can produce more risky candidates. The bot still performs security checks; a lower score threshold is not a guarantee that a token is safe.
